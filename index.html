操作演示

Walkthrough

按界面完成每一步

Follow the interface step by step

步骤 01
STEP 01

创建 API 密钥

Create an API key

进入“API 密钥”，点击“创建密钥”。名称可自由填写，分组代表不同的价格倍率与稳定性。特价组价格最低，但可能出现错误或断连。

Open API Keys and select Create API Key. The name is up to you. Groups have different prices and stability. The special-price group costs less but may return errors or disconnect.

按需要选择分组。较高倍率通常意味着更好的稳定性和更高价格。
Select a group for the task. A higher multiplier usually means more stability and a higher price.
步骤 02
STEP 02

导入到 CC Switch

Import to CC Switch

先打开 CC Switch。回到 API 密钥列表，点击该密钥右侧的“导入到 CCS”，浏览器出现提示时选择打开 CC Switch，然后在确认窗口点击“导入”。

Open CC Switch first. Return to API Keys, select Import to CCS for the relevant key, allow the browser to open CC Switch, then select Import in the confirmation window.

步骤 03
STEP 03

确认配置并选择模型

Confirm configuration and choose a model

导入成功后，CC Switch 中会显示该供应商配置。打开 ChatGPT，看到服务标识即代表配置可用。根据任务复杂度选择模型。

After a successful import, the provider appears in CC Switch. Open ChatGPT. When the service indicator is visible, the configuration is ready. Choose a model by task complexity.

通道状态

Channel status

先看状态，再开始任务。

Check the channel before you start.

通道卡片右侧的颜色代表当前可用情况。页面会定期刷新数据，高延迟时可稍后再试。

The color at the right side of a channel card shows current availability. Data refreshes periodically. Try again later when latency is high.

绿色：可用

服务运行正常，可直接使用。

黄色：可用但延迟高

可以发送请求，但响应速度可能较慢。

红色：不可用

等待恢复后再尝试。

Green: available

The service is operating normally.

Yellow: available with high latency

You can send requests, but responses may be slower.

Red: unavailable

Please wait for recovery and try again.

FAQ

常见问题

Frequently asked questions

在哪里下载 CC Switch？

请前往 farion1231/cc-switch Releases 下载最新版本。

为什么倍率会变化？

倍率会随账号运营成本上下调整，通常变化不大也不频繁。特殊情况以群内通知为准。

为什么无法连接？

平台不面向中国大陆、香港和澳门地区的访问。请确认你满足授权测试与地区要求。

为什么无法使用 Luna 或生图？

Luna 默认可能关闭，是否可用请以当时的模型菜单与通道状态为准。

Where can I download CC Switch?

Download the latest release from farion1231/cc-switch Releases.

Why does the multiplier change?

The multiplier may move with account operating cost. Changes are usually small and infrequent. Refer to group announcements for exceptional cases.

Why can I not connect?

The platform does not provide access from mainland China, Hong Kong, or Macao. Confirm that you meet the authorized testing and regional requirements.

Why is Luna or image generation unavailable?

Luna may be disabled by default. Check the model menu and channel status at the time you use it.
